# Practice-future

**Practice-future** — многостраничный сайт, созданный для тренировки навыков **SASS**, **БЭМ** и **JavaScript**.  
Основное внимание уделено качеству верстки и доступности (**accessibility**).

## Особенности

- Адаптивная верстка для всех типов устройств  
- Бургер-кнопка с плавной анимацией  
- Кастомный селект с поддержкой клавиатурного управления  
- Табы и аккордеоны  
- Кастомный видеоплеер  
- Семантическая разметка и aria-атрибуты для повышения доступности

## Технологии

- HTML5  
- SASS / SCSS  
- Методология БЭМ  
- Vanilla JavaScript
